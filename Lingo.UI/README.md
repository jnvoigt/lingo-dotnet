# Lingo UI (GUI Editor)

Cross-platform desktop graphical user interface editor for the Lingo localization toolkit, built with [Avalonia UI](https://avaloniaui.net/) and .NET 10.

## Overview

Lingo UI provides visual localization editing, directory synchronization, and format-agnostic translation management across Linux, macOS, and Windows.

For detailed architecture, functional requirements, and UX specifications, see [GUI_SPECIFICATION.md](../GUI_SPECIFICATION.md).

## Running the Application

```bash
dotnet run --project Lingo.UI
```
