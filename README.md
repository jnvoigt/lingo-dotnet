# Lingo Toolkit

Format-agnostic localization toolkit. Currently focused on XLIFF support.

[//]: # (![License]&#40;https://img.shields.io/github/license/lingo-opensource/lingo&#41;)

> **Work in progress**
> Lingo is currently in very early development. Core models and XLIFF (1.2, 2.0) support are being implemented. CLI and other formats are not yet functional.

## Supported Formats

- XLIFF (1.2, 2.0) - *In Progress*
- More planned (Android XML, Godot PO, Factorio CFG, etc.)

## Development

Currently, the project is in a scaffolding phase.

### Building

```bash
dotnet build
```

### Testing

```bash
dotnet test
```
